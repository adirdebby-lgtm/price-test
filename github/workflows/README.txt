בדיקת היתכנות - קבצי מחירים (שופרסל, רמי לוי, יוחננוף, חצי חינם)
1. ב-github.com: New repository (שם: price-test, Public).
2. Add file > Upload files: מעלים את התיקייה הזו כולל .github (גוררים את כל הקבצים).
3. לשונית Actions > "בדיקת קבצי מחירים" > Run workflow.
4. כשמסתיים (עד כ-25 דקות) פותחים את הריצה > test > "Run python test_prices.py" ושולחים לי את הסוף שלו (החלק שמתחיל ב-SUMMARY).
